# Newest Changes

- **New Features**
  - Added the _Author_ field to Finder templates.
  - Added a subcommand to validate templates.
  - Enabled installation of templates from the web.
  - Improved Finder search functionality; fixed minimum requirements in the template creator.
  - Finder templates now support the extensions [.json, .jsonc, .json5].
- **Bug Fixes**
  - Fixed issues with the minimum requirement logic in the template creator.
  - Regex is no longer supported in the _name_ field, only in _name_regex_.
